# Web 查看器

## 打开或切换记忆库

MCP 客户端启动 Labradorite 后，服务会启动查看器。桌面环境会尝试打开浏览器。核对「当前目录」，点击「打开记忆库」即可进入。

要打开另一个库，点击「更换目录」，找到包含 `runtime.json` 的文件夹，依次点击「使用此目录」和「打开记忆库」。进入记忆库后，也可以从导航栏的「切换记忆库」返回入口。

## 浏览和搜索

页面顶部的「全库搜索」可以一起查找经历、材料、照片描述和人物。要缩小范围，可以进入相应页面，使用该页的「筛选」按钮。

- **经历**默认按发生时间排序。比如今天补录了上个月的旅行，并注明了旅行日期，就能按发生时间在上个月找到它。想看今天整理过哪些经历，可以将「时间依据」改为「记录时间」。起止时间需包含时区，例如 `2026-10-01T00:00:00+08:00`。勾选「仅发生时间未知」可找出待补日期的经历。
- **人物档案**可以按姓名或身份线索查找。打开人物后，可以对照当前和以往的印象，再点开当时作为依据的经历版本。
- **相册和材料**可以追溯原文。打开照片或视频，可以看到引用它的经历。从经历详情的「原始材料」也可以回到对应记录。

## 审阅或撤销回顾

模型保存回顾后，打开「回顾记录」。列表按保存顺序排列，最近一次在最上方。即使模型今天整理的是上个月的旅行，这次修改也会出现在今天的回顾中。

1. 打开一条回顾。修订过的经历会分别展示「修改前」和「修改后」。如果同次回顾更新了人物印象，也能看到先前印象、本次印象和依据的经历版本。
2. 点开原始材料核对内容。核对完成后点击「标为已审阅」。已经标记的回顾仍可撤销。
3. 需要撤销时，展开「撤销本次回顾」，先查看将移除哪些新增记录、哪些内容会恢复到之前的版本，再点击「确认撤销」。同次回顾中的经历和人物变动会一起撤销，原始材料保留。

若页面显示「暂时无法撤销」，请查看列出的原因。例如，后来的人物印象引用了这次经历，可以先核对那条人物回顾。如果决定撤销两条，先撤销后写入的人物回顾，再回到这次经历。仅触发索引的空回顾没有保存内容，不会出现在列表中。

## 设定与自主变化

打开「设定」可以新增角色或世界设定，选择「主人维护」或「允许自主变化」。角色设定在同一空间的各个世界生效，世界设定仅在当前空间的指定世界生效。点击已生效的设定可以编辑内容或修改权限。

模型首次提出新设定时，先进入「待主人确认」。在「回顾记录」打开该项，核对理由和依据的经历，选择生效后的修改方式，再确认或拒绝。「主人维护」的修订也要确认；「允许自主变化」的修订会立即生效，之后仍可标为已审阅。

若不同意某次变化，打开该版本，展开「撤销这条设定变化」并确认。上一版内容和修改权限一起恢复；撤销首次生效的版本会移除当前设定。引用的经历和其他设定保留。有后续生效版本时，可以先核对当前版本。角色下次读取设定时也能看到主人拒绝或撤销过的判断。

## 索引状态与设置

「索引状态」显示已索引和待处理的片段数、当天请求用量及最近任务的状态。点击「刷新状态」只会重新读取进度。要调整空闲索引时长或每日请求上限，打开「设置」，保存后重启该记忆库的 MCP 服务。参数范围和配置示例见[运行时设置](settings.md)。

## 找回登录链接或从远程访问

浏览器没有自动打开时，在运行服务的机器上，以启动服务的同一系统账号进入项目目录并运行：

```sh
vpr viewer:url
```

在本机使用时，打开输出中对应记忆库的登录链接即可。如果服务运行在远程机器上，在自己的电脑执行输出的 SSH 转发命令，将 `user@server` 换成实际账号和服务器地址。保持 SSH 连接，再在本机浏览器打开该登录链接。「更换目录」浏览的是服务器上的文件夹。

如果命令提示没有运行中的查看器，请在 MCP 客户端启动 Labradorite，并检查配置的 `args`。其中的 `"--no-webview"` 会关闭查看器自动启动。添加或移除该参数后，重启服务即可生效。
