# Labradorite

启动 stdio MCP 记忆服务时会自动启动只读查看器。桌面会尝试打开浏览器，SSH 环境可在服务的标准错误日志中找到登录链接。只运行记忆服务时，在 MCP 配置的 `args` 数组中加入 `"--no-webview"`，然后重启服务。

打开网页后点击“打开当前记忆库”。要查看另一份库，展开“选择其他目录”。全库搜索同时查找经历、文本和相册材料；选择“仅本地全文”即可完全在本机搜索。打开照片或材料后，可沿“关联经历”返回引用它的最新经历。

无桌面服务器上，使用启动服务的同一系统账号，在项目目录运行：

```sh
node dist/src/viewer-url.js
```

命令列出正在运行的查看器、可重新打开的登录链接，以及按实际端口生成的 SSH 转发命令。在自己的电脑执行该 SSH 命令（替换 user@server），然后打开登录链接。网页浏览的是服务器上的记忆库。
