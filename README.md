# Labradorite

启动 stdio MCP 记忆服务时会自动启动只读查看器。桌面会尝试打开浏览器，SSH 环境可在服务的标准错误日志中找到登录链接。只运行记忆服务时，在 MCP 配置的 `args` 数组中加入 `"--no-webview"`，然后重启服务。

浏览器打开后，选择包含 `runtime.json` 的数据目录，点击“打开此记忆库”。页面中的“切换记忆库”可重新选择目录。

在无桌面服务器上运行服务时，在自己的电脑执行 `ssh -N -L 4317:127.0.0.1:4317 user@server`，再用浏览器打开服务日志中的完整登录链接。如果服务分配了其他端口，将命令中的两个 4317 换为实际端口。网页浏览服务器上的目录。
